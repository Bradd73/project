System Requirements Needed to Run the Games You Want!

Hover over each category to learn more about system requirements!

Storage

Most modern games require between 50GB and 150GB of storage space.

Graphics Card

A dedicated graphics card helps display detailed graphics and run games smoothly.

RAM

16GB of RAM is recommended for most modern PC games.

Processor (CPU)

A modern Intel Core i5 or AMD Ryzen 5 is a good starting point for gaming.
